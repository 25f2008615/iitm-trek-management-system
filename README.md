# iitm-trek-management-system
A Trek Management System built using Flask, SQLite, SQLAlchemy, Jinja2, and Bootstrap as part of the IIT Madras Online BS in Data Science - Modern Application Development I project.
## Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- Jinja2
- Bootstrap

Project initialization completed. Development in progress.
